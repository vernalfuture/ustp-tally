# ustp-tally

The public tally library and verifier CLI for USTP Hub (ADR 0009 in the private ggrow3/USTPVote
monorepo). The voting app pins an exact version, and every election record names it. The
counting rules are in docs/spec.md; choices the design left open are in docs/adr/.

## Commands

- pnpm install | pnpm lint | pnpm typecheck | pnpm test | pnpm build
- pnpm format:check before a pull request.
- node scripts/fixtures/<name>.mjs <downloaded source> re-creates a fixture's ballots.json.

## Layout

- src/: the library. Pure functions only: no I/O, clock, randomness, or Node built-ins. ESLint
  enforces it.
- src/cli/: the verifier, the only code that reads files or uses Node's crypto.
- src/test-support/: test helpers, not shipped.
- fixtures/: past USTP votes with cited sources; src/fixtures.test.ts checks them.

## Rules

- Start every change with a failing test.
- Never invent a ballot. A fixture's published.json is transcribed by hand from a cited source,
  never generated by this engine. Votes that need ballots nobody published stay pending.
- Fixtures hold anonymous ballot contents only, in canonical sorted order: no voter IDs, names,
  emails, or timestamps.
- Any change to what the tally outputs for some input is a new version. Keep ENGINE in
  src/engine.ts equal to package.json.
- One runtime dependency (@noble/hashes), pinned exactly. Adding one needs an ADR.
- Claude Code never creates the GitHub repository, pushes, tags, or publishes the package.
